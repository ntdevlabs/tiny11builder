# 支持 Tiny11 Builder（简体中文）

[English](support.md) | 简体中文

Tiny11 Builder 完全免费，包括所有构建模式与移除选项。可选的支持用于资助开发时间、跨 Windows 版本的测试以及已报告问题的修复。

**[GitHub Sponsors 按月支持](https://github.com/sponsors/ntdevlabs)** ·
**[Ko-fi 一次性捐赠](https://ko-fi.com/ntdev)**

其他平台：[Patreon](https://www.patreon.com/ntdev) ·
[PayPal](https://paypal.me/ntdev2)。

你还可以通过报告可复现的 Bug、在虚拟机中测试输出以及分享[视频演示](https://youtu.be/LfEWIz5mQ8A)来帮助项目。提交 Bug 时请附上应用版本、映像 build 号、所选选项与相关日志；分享日志前请移除个人路径与私密信息。

## 项目动态

每个版本的说明都会链接到对应的源码，并描述修复内容、已知限制与剩余工作。进度更新请保持具体：修复了什么、测试了什么、还有什么需要做。只有当资金目标反映真实、有据可查的成本时才设定；本文不声称任何目标或支出数字。
