# Support Tiny11 Builder

English | [简体中文](support.zh-CN.md)

Tiny11 Builder is free, including all build modes and removal options.
Optional support helps fund development time, testing across Windows
releases and fixes for reported problems.

**[Monthly support on GitHub Sponsors](https://github.com/sponsors/ntdevlabs)** ·
**[One-time donation on Ko-fi](https://ko-fi.com/ntdev)**

Other options: [Patreon](https://www.patreon.com/ntdev) ·
[PayPal](https://paypal.me/ntdev2).

You can also help by reporting reproducible bugs, testing output in a VM
and sharing the [video demo](https://youtu.be/LfEWIz5mQ8A). Include your
app version, image build, selected options and relevant logs in bug reports;
remove personal paths and private information before sharing logs.

## Project updates

Each release's notes link to the corresponding source and describe fixes,
known limitations and any remaining work. Keep progress updates specific:
what was fixed, what was tested and what still needs work. Set a funding goal
only when it reflects a real, explained cost; no target or spending figure is
claimed here.
